# Publication Releases

Durable public repository for BiobitWorks/Cellico publication-version release packages, organized by destination site.

## Sites

- [`sites/zenodo/`](sites/zenodo/) — Zenodo preprint/package upload bundles and per-date metadata.
- [`sites/hugging-face/`](sites/hugging-face/) — Hugging Face model/package release notes and release-asset hashes.
- [`sites/github/`](sites/github/) — GitHub publication receipts, repo manifests, and public-release records.

## Current Release

- [`2026-08-04 Zenodo packages`](sites/zenodo/2026-08-04/)
- [`2026-08-04 Hugging Face model`](sites/hugging-face/2026-08-04/)
- [`2026-08-04 GitHub receipt`](sites/github/2026-08-04/)

Large model artifacts are attached to GitHub Releases when they exceed normal git file limits.

## Boundaries

This repository tracks site-specific publication packages and receipts. It does not itself perform Zenodo upload, Hugging Face upload, live KG writeback, PI countersignature, or claim promotion unless a site receipt explicitly says so.
